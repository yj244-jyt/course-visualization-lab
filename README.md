# Course Visualization Lab

Interactive visual explanations for course concepts.

Live site: <https://yj244-jyt.github.io/course-visualization-lab/>

## Current visualizations

- Fourier transform, frequency centering, circular low-pass masks, and inverse reconstruction

## Repository structure

```text
assets/                         Gallery styles and behavior
visualizations/catalog.json     Published visualization index
visualizations/<slug>/          Standalone interactive explainers
skills/course-visualization-publisher/
                                Reusable Codex publishing skill
```

The site deploys automatically to GitHub Pages after changes are pushed to `main`.
