金字塔融合：Mask 决定从哪里取图

用你提供的苹果 A 和橙子 B，观察「选区域 → 分频率融合 → 重建」。图像都是 512 × 512 RGB；坐标 (行, 列) 从 0 开始。

同一个位置，究竟用了谁？

1 层时 F(p) = M₀(p)A(p) + (1−M₀(p))B(p)。多层时，各频带使用不同的 Mₖ；放大重建还会汇集邻域，所以不能给最终像素指定一个通用的「原图 A 占 70%」比例。

01 · 设计分界线，比较硬拼接

每个位置使用同一坐标的 A[i,j] 和 B[i,j]。原始 mask[i,j] 为 1 就选 A，为 0 就选 B。

竖线模式按列 j 判断：j < t 为 A 选区（左），j ≥ t 为 B 选区（右）。水平模式按行 i 判断：i < t 为 A 选区（上），i ≥ t 为 B 选区（下）。

这些选区描述的是原始二值 mask／硬拼接；多层融合会在选区边界附近产生过渡。算法不识别水果，也不自动选择分界线。


Mask 就是每个位置的选择权重


结果 = mask × A + (1 − mask) × B


  • mask = 1：1A + 0B = A，保留 A 的这个位置。
  • mask = 0：0A + 1B = B，保留 B 的这个位置。


所以只需要设计一个 mask，另一个图的权重直接用 1 - mask，两者互补。


在金字塔较粗层，mask 平滑后可能变成 0.7，此时就是：


0.7 × A 的这一层 + 0.3 × B 的这一层


这样边界就能从“选择其中一张”逐渐变成“两张按比例过渡”。


02 · 在同一层，把 Mask 对应到两张图
Cₖ(i,j,c) = Mₖ(i,j) × Lᴬₖ(i,j,c) + [1−Mₖ(i,j)] × Lᴮₖ(i,j,c)
每层 mask 的高宽与图像层一致。Python 中 M[..., None] 把 (Hₖ,Wₖ) 变成 (Hₖ,Wₖ,1)，同一个权重同时作用于 R、G、B。较粗层的灰色区域表示混合权重，并不是物体的灰度。
所有层在页面上放大到相同显示大小，实际数组尺寸会减小。红色表示正残差，蓝色表示负残差，白色表示 0；每组残差使用共同的对称色标，只显示红通道。最粗一层保存 RGB 高斯图，不是残差。
对应 Python：建立金字塔和逐层融合
GA = gaussian_pyramid(A, num_levels)
GB = gaussian_pyramid(B, num_levels)
LA = laplacian_pyramid(GA)
LB = laplacian_pyramid(GB)
GM = gaussian_pyramid(mask, num_levels)

blended = []
for k in range(num_levels):
    M = GM[k][..., None]
    blended.append(M * LA[k] + (1 - M) * LB[k])

# G[k+1] = reduce_image(G[k])
# L[k] = G[k] - expand_image(G[k+1], G[k].shape)
# L[-1] = G[-1]


03 · 从粗到细，加回各层细节
Rₙ₋₁ = Cₙ₋₁
Rₖ = expand(Rₖ₊₁, shape(Cₖ)) + Cₖ
先从小尺寸的融合高斯图起步，逐层扩大、补回对应尺度的细节，最终回到 512 × 512。
残差必须保留正负号。负值表示要从粗层预测中减去亮度；把负值截成 0 会丢掉重建所需的信息。
result = blended[-1].copy()
for k in range(len(blended)-2, -1, -1):
    result = expand_image(
        result, blended[k].shape
    ) + blended[k]
return result  # 不 clipping
实现约定
使用作业的 5 × 5、σ = 1、总和为 1 的高斯核。Reduce 先 reflect 平滑，再取偶数行列。
Expand 插零到两倍尺寸，再使用增益 4 的同一高斯核插值，最后裁剪到目标尺寸。RGB 三个通道独立处理。
所有中间数组均为 Float64；图像仅在显示时截到 [0,1]。显示截断不会写回重建数据。


04 · 同一条分界线，1–6 层会怎样？
1 层就是硬拼接。更多层引入更大空间尺度的融合，通常让颜色接缝更柔和；图像中的轮廓错位仍然存在，也可能产生重影。图层数改变过渡尺度，mask 几何形状决定你希望从哪里切换来源。
