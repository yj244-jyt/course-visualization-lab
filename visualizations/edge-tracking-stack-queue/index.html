两侧网格中的 S / W / . 始终表示输入。绿色表示已写入输出；橙色实框是正在处理的像素，紫色虚框是正在检查的邻居。小数字表示取出处理的次序，连线表示首次发现该像素的传播路径。

已接纳尚未接纳的弱边缘

先点「下一步」观察传播，再把步长改成「逐条操作 / 邻居」：代码高亮会跟随取出、条件判断、标记和加入容器。两侧按各自执行进度前进，不保证正在处理同一个坐标。

固定邻居顺序：左上 → 上 → 右上 → 左 → 右 → 左下 → 下 → 右下。Stack 从最后加入的一端取出；Queue 从最先加入的一端取出。只走合法像素，绝不跨过 .。

相同的接纳条件

weak[ni, nj] and not edges[ni, nj]

第一个条件拒绝 suppressed 像素；第二个条件避免重复发现和循环。接纳时先写入 True，再加入容器，因此同一像素最多加入一次。刚接纳的弱边缘还未被处理，但已经属于最终输出。

输入是两个 H × W Boolean 数组，输出也是 H × W Boolean 数组。strong.copy() 创建独立输出，整个搜索不修改 strong 或 weak。

一个 . 只阻断经过它的路径；二维中若存在其他 8 邻域路径，仍可以绕行。没有任何强边缘时，即使弱边缘互相连成一片，也全部删除。

每个像素至多处理一次，每次检查最多 8 个邻居。两种实现时间均为 O(HW)，最坏额外空间均为 O(HW)。

配套 get_neighbors 与双阈值约定

示例代码假定已导入 numpy as np。下列 helper 给出本演示使用的确定邻居顺序。

def get_neighbors(i, j, H, W):
    return [(i + di, j + dj)
            for di in (-1, 0, 1)
            for dj in (-1, 0, 1)
            if (di != 0 or dj != 0)
            and 0 <= i + di < H
            and 0 <= j + dj < W]

weak = (nms > low) & (nms <= high)
