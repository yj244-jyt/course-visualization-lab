一个像素的梯度角度，到底指向哪里？

调节 Gx、Gy，从局部亮度差分一路追踪到向量、角度和 NMS 比较方向。

∇I = [Gx, Gy] · G ≥ 0 · θ ∈ [0°, 360°)

1. 局部亮度产生两个分量

I[y, x]

每向右一格亮度改变 Gx，每向下一格改变 Gy。中心差分分别比较左右和上下。

2. 两个分量合成一个梯度向量

∇I = (Gx, Gy)

箭头指向亮度增长最快的方向。拖动图中的箭头端点，或使用上方滑杆。

3. 长度与角度各回答一个问题

G, θ
梯度大小 G5.00
方向 θ53.13°
边缘有多强？看向量长度 G = √(3² + 4²) = 5
亮度朝哪里增长？看向量角度 θ = degrees(atan2(4, 3)) % 360 = 53.13°
0°向右：Gx > 0，Gy = 0
90°向下：图像的 y 坐标向下增加
180°向左：Gx < 0，Gy = 0
270°向上：Gy < 0

4. NMS 为什么要使用这个角度？

梯度垂直穿过边缘；因此沿梯度方向比较，才能从粗响应中留下峰值。

原始 θ53.1°
θ mod 18053.1°
量化方向45°
angle = theta[i, j] % 180

# 依据 0° / 45° / 90° / 135°
# 选择梯度方向两侧的邻居
q, r = neighbors_along_gradient(...)

if G[i, j] >= q and G[i, j] >= r:
    out[i, j] = G[i, j]
else:
    out[i, j] = 0
一句话：Gx 和 Gy 是一个像素处的两个坐标分量；G 是这支箭头的长度；theta 是它从向右方向开始、在图像坐标中顺时针量出的朝向。它指向亮度增加最快的方向，而真实边缘方向与它垂直。
