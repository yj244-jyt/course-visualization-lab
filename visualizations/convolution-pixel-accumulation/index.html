当前这一项

固定 i=2, j=2
行：image_i = 2 + 0 - 1 = 1 列：image_j = 2 + 0 - 1 = 1
sum₁ = 0 + image[1,1] × Kflip[0,0] = 0 + 5 × 0 = 0
坐标有效，执行乘法并用 += 加到同一个 out[i,j]。
for i in range(Hi):
for j in range(Wi): # 外层固定一个 out[i,j]
for ki in range(Hk):
for kj in range(Wk): # 内层依次检查 9 项
image_i = i + ki - pad_h
if 0 <= image_i < Hi and 0 <= image_j < Wi:
out[i,j] += image[image_i,image_j] * flipped_kernel[ki,kj]
循环关系：当前固定 1 个输出位置，内层依次检查 3×3 = 9 个 kernel 位置；5×5 输出共有 25 个外层位置，因此概念上共有 25×9 = 225 项。

if 与 np.pad 是两种等价实现

padded = np.pad(image, ((1, 1), (1, 1)), mode="constant")

当前动画先算原图坐标，再用 if 跳过越界项。若先显式补零，内层可直接读取 padded[i + ki, j + kj]，不再减 padding，也不需要边界判断。

奇数 kernel 有唯一中心，偶数 kernel 没有

4×4 same output: padding 可选 ((1, 2), (1, 2))

3×3 的中心索引明确是 (1,1)。4×4 要保持输出同尺寸，总 padding 是 3，必须拆成 1+2 或 2+1；两种约定会产生一像素的对齐差异。
